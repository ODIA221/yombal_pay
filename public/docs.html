Documentation YombalPay

YombalPay permet à un site ou à une boutique d'encaisser en Bitcoin (réseau Lightning) avec des prix en FCFA. Vous envoyez un montant en FCFA, nous créons la facture Lightning, votre client paie depuis n'importe quel pays, et nous vous prévenons dès que c'est payé.

Il y a deux façons d'utiliser YombalPay :

  • Sans code : depuis votre tableau de bord, vous créez une page de paiement et vous montrez son QR code au client. Voir Encaisser sans site web.
  • Avec l'API : votre site web crée les paiements automatiquement. C'est le reste de cette page.

Démarrage rapide

Votre premier paiement test en cinq minutes.

  1. Créez un compte sur la page d'inscription. Votre clé API secrète s'affiche une seule fois : copiez-la. Elle commence par sk_test_.
  2. Créez un paiement depuis votre serveur, en remplaçant VOTRE_CLE : 
    curl https://api.yombalpay.sn/v1/checkouts \
  -u VOTRE_CLE: \
  -H "Content-Type: application/json" \
  -d '{"amount": 5000, "currency": "XOF", "reference": "commande-1042"}'
    La réponse contient une adresse url : c'est la page de paiement.
  3. Envoyez votre client sur cette url. Il voit le montant en FCFA et en sats, et un QR code à scanner avec son portefeuille Lightning.
  4. Soyez prévenu : ajoutez webhook_url à votre requête, et YombalPay appellera cette adresse dès que le paiement est confirmé. Voir Webhooks.

En local, remplacez https://api.yombalpay.sn par l'adresse de votre serveur YombalPay, par exemple http://localhost:3000. Votre tableau de bord l'affiche dans l'onglet Développeurs.

Encaisser sans site web

Pour une boutique physique ou une vente sur WhatsApp, pas besoin de développeur :

  1. Ouvrez votre tableau de bord et cliquez sur Encaisser.
  2. Tapez le montant en FCFA et une description, puis cliquez sur Créer la page de paiement.
  3. Montrez le QR code à votre client, ou envoyez-lui l'adresse de la page. Le paiement apparaît dans votre tableau de bord dès qu'il est confirmé.

Authentification

Chaque requête porte votre clé secrète, d'une de ces deux façons :

Authorization: Bearer sk_test_…        # en-tête HTTP
curl -u sk_test_…: …                  # avec curl, la clé suivie de « : »

La clé secrète reste sur votre serveur. Ne la mettez jamais dans le code de votre site web visible par les visiteurs, ni sur GitHub. Si elle a fuité, générez-en une nouvelle depuis le tableau de bord : l'ancienne cesse aussitôt de fonctionner.

Référence API

Adresse de base : https://api.yombalpay.sn/v1. Les corps de requête et de réponse sont en JSON.

POST/v1/checkouts

Crée un paiement. Le montant en sats est calculé au cours du moment et reste valable 15 minutes.

ChampTypeDescription
amount obligatoireentierMontant en FCFA, au moins 50.
currency facultatiftexteXOF (franc CFA), seule devise acceptée pour l'instant.
reference facultatiftexteVotre numéro de commande. Renvoyer la même référence redonne le même paiement : pas de doublon si votre site réessaie.
description facultatiftexteAffichée au client sur la page de paiement.
return_url facultatifURLOù renvoyer le client après le paiement.
webhook_url facultatifURLOù envoyer la notification checkout.paid.

GET/v1/checkouts/:id

Renvoie un paiement. Son statut est vérifié auprès du réseau au moment de l'appel.

GET/v1/checkouts

Renvoie vos 100 derniers paiements, du plus récent au plus ancien.

POST/v1/checkouts/:id/simulate_payment

Mode test seulement : marque le paiement comme payé, comme si le client avait payé. Voir Mode test.

StatutSignification

Erreurs

En cas d'erreur, la réponse contient un message en français :

{ "error": { "type": "invalid_request_error", "message": "amount doit être un entier en FCFA, au moins 50." } }

Webhooks

Un webhook est un message que YombalPay envoie à votre serveur quand un paiement est confirmé. Votre site n'a pas besoin de demander le statut en boucle : c'est nous qui vous prévenons.

Si vous avez donné un webhook_url, nous y envoyons un POST :

{
  "id": "evt_3c1e…",
  "type": "checkout.paid",
  "created_at": "2026-10-18T10:43:10Z",
  "data": { "id": "chk_f81125f2a800b3ad", "status": "paid", "reference": "commande-1042", "amount": 5000, … }
}

Vérifier que le message vient bien de YombalPay

Chaque message porte un en-tête Yombal-Signature: t=…,v1=…. v1 est le HMAC-SHA256 de t + "." + corps avec votre secret de webhooks (tableau de bord, onglet Développeurs). Refusez tout message dont la signature ne correspond pas.

// Node.js avec Express
import crypto from "node:crypto";

app.post("/hooks/yombalpay", express.raw({ type: "application/json" }), (req, res) => {
  const { t, v1 } = Object.fromEntries(req.get("yombal-signature").split(",").map((p) => p.split("=")));
  const attendu = crypto.createHmac("sha256", process.env.YOMBAL_WEBHOOK_SECRET)
    .update(`${t}.${req.body}`).digest("hex");
  if (attendu !== v1) return res.status(400).end();       // pas de YombalPay : on refuse

  const event = JSON.parse(req.body);
  if (event.type === "checkout.paid") {
    // marquer la commande event.data.reference comme payée
  }
  res.json({ received: true });
});

Répondez avec un code 200. Sinon, nous réessayons jusqu'à 3 fois (après 2 s, 10 s et 30 s).

Mode test

Avec une clé sk_test_, les factures sont sur le réseau Bitcoin de test (elles commencent par lntb). Aucun vrai bitcoin n'est dépensé.

Pour simuler un paiement réussi sans portefeuille de test :

  • sur la page de paiement, cliquez sur Simuler le paiement (mode test) ;
  • ou appelez POST /v1/checkouts/:id/simulate_payment.

Le paiement passe à paid et votre webhook est envoyé, exactement comme en vrai.

Exemples par langage

Votre site est écrit dans un langage de programmation. Choisissez le vôtre : c'est la même requête (« crée un paiement de 5 000 FCFA ») écrite de quatre façons. cURL se lance dans un terminal, pratique pour tester. Node.js (JavaScript), Python et PHP sont les langages les plus courants pour les sites web : WordPress, par exemple, est en PHP.

curl https://api.yombalpay.sn/v1/checkouts \
  -u VOTRE_CLE: \
  -H "Content-Type: application/json" \
  -d '{"amount": 5000, "currency": "XOF", "reference": "commande-1042"}'
const res = await fetch("https://api.yombalpay.sn/v1/checkouts", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.YOMBAL_SECRET_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ amount: 5000, currency: "XOF", reference: "commande-1042" }),
});
const paiement = await res.json();
// rediriger le client vers paiement.url
import os, requests

paiement = requests.post(
    "https://api.yombalpay.sn/v1/checkouts",
    auth=(os.environ["YOMBAL_SECRET_KEY"], ""),
    json={"amount": 5000, "currency": "XOF", "reference": "commande-1042"},
).json()

# rediriger le client vers paiement["url"]
$ch = curl_init('https://api.yombalpay.sn/v1/checkouts');
curl_setopt_array($ch, [
  CURLOPT_USERPWD        => getenv('YOMBAL_SECRET_KEY') . ':',
  CURLOPT_HTTPHEADER     => ['Content-Type: application/json'],
  CURLOPT_POSTFIELDS     => json_encode(['amount' => 5000, 'currency' => 'XOF', 'reference' => 'commande-1042']),
  CURLOPT_RETURNTRANSFER => true,
]);
$paiement = json_decode(curl_exec($ch), true);
header('Location: ' . $paiement['url']);   // rediriger le client
