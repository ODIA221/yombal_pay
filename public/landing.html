Expérience développeur

Pensé pour les développeurs d'Afrique et d'ailleurs.

Une requête HTTP pour créer un paiement, un webhook signé pour le confirmer. Idempotence et vérification du statut intégrées.

  1. Récupérez vos clés API

    Une clé de test et une clé de production. Authentification par jeton Bearer standard.

    sk_test_tp_9Xk2mR7vDakar2026

    Mode test : les paiements sont simulés, aucun vrai sats n'est débité.

  2. Créez un paiement

    Envoyez un montant en XOF. YombalPay renvoie l'URL de la page de paiement et la facture BOLT11.

  3. Recevez les webhooks signés

    Dès que le paiement est confirmé, votre serveur reçoit checkout.paid, signé en HMAC-SHA256.

Choisissez le langage de votre site : c'est la même requête (« crée un paiement de 5 000 FCFA ») écrite en Node.js, Python ou PHP. cURL sert à la tester directement dans un terminal.

const res = await fetch("https://api.yombalpay.sn/v1/checkouts", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.YOMBAL_SECRET_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    amount: 5000,
    currency: "XOF",
    reference: "commande-1042",
    webhook_url: "https://maboutique.sn/hooks/yombalpay",
  }),
});
const checkout = await res.json();
// checkout.url : page de paiement · checkout.amount_sats : 10 513

$ch = curl_init('https://api.yombalpay.sn/v1/checkouts');
curl_setopt_array($ch, [
  CURLOPT_USERPWD        => getenv('YOMBAL_SECRET_KEY') . ':',
  CURLOPT_HTTPHEADER     => ['Content-Type: application/json'],

$checkout = json_decode(curl_exec($ch), true);
header('Location: ' . $checkout['url']);

Confiance

Votre argent et vos clés restent protégés

Requêtes signées

Chaque appel vers Bitnob est signé en HMAC-SHA256. Votre clé secrète ne quitte jamais le serveur.

Statut vérifié côté serveur

Un paiement passe à « Payé » seulement après confirmation par l'API Bitnob, jamais sur la seule foi d'un webhook ou du navigateur.

Aucun double encaissement

Chaque événement n'est traité qu'une fois, et la même reference renvoie toujours le même paiement.

Prix figé en FCFA

Le montant en sats est fixé à la création du paiement et reste valable 15 minutes.
